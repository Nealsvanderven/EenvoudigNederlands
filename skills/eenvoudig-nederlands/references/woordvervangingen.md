## Engelse woorden met een gewoon Nederlands woord

| supporten | ondersteunen |

| user | gebruiker |
| default | standaard |
| performance | snelheid (geef het getal) |
| impact | gevolg |
| challenge | probleem |
| tooling | hulpmiddelen |
